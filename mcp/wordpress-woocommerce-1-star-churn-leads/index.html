2. Public REST + RSS Pipeline Architecture (Zero Proxies)

  1. WordPress.org Field-Projected REST API (api.wordpress.org/plugins/info/1.2/): Requesting only active_installs, downloaded, ratings, support_threads, support_threads_resolved, homepage, tested, and requires_php while disabling description, sections, and versions shrinks response payloads by ~95%.
  2. Direct 1★–2★ Review & Unresolved Ticket RSS Feeds: WordPress.org exposes clean XML feeds at /support/plugin/<slug>/reviews/feed/?filter=1, ?filter=2, and /support/plugin/<slug>/unresolved/feed/ — removing fragile HTML pagination completely.
  3. Atlassian Marketplace REST v2 (/rest/2/addons): Returns install counts, active user footprints, Cloud Fortified & Partner Tier metadata, pricing tables, and 1★–2★ customer complaints. Note that /rest/2/vendors/{vendorId} returns HTTP 410, so partner contact enrichment pairs REST v2 addon records with live Marketplace partner listings.

Quick Zero-Key Python Probe (WordPress.org + Atlassian REST v2)

probe_wp_atlassian_churn.py 
import json, urllib.request

# 1. WordPress.org Plugins API 1.2 (WooCommerce PayPal Payments)
wp_url = (
    "https://api.wordpress.org/plugins/info/1.2/?action=plugin_information"
    "&request[slug]=woocommerce-paypal-payments"
    "&request[fields][description]=0&request[fields][sections]=0"
    "&request[fields][active_installs]=1&request[fields][ratings]=1"
    "&request[fields][support_threads]=1&request[fields][support_threads_resolved]=1"
)
wp = json.loads(urllib.request.urlopen(wp_url, timeout=15).read())
print("WP:", wp["slug"], "installs:", wp["active_installs"], "1-star:", wp["ratings"]["1"])

# 2. Atlassian Marketplace REST v2 (public Jira Cloud time-tracking addons)
atl_url = "https://marketplace.atlassian.com/rest/2/addons?text=time+tracking&hosting=cloud&limit=3"
atl = json.loads(urllib.request.urlopen(atl_url, timeout=15).read())
for addon in atl.get("_embedded", {}).get("addons", []):
    print("Atlassian:", addon["key"], "|", addon["name"])
