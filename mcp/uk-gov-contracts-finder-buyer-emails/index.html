1. Where Direct Buyer Emails Live in the UK OCDS Schema

In UK Contracts Finder OCDS releases, buyer contact details sit inside the parties[] array rather than the top-level tender object. Resolving the right party requires inspecting roles in priority order:

  1. Buyer Role Resolution: Match parties[] entries containing roles.includes("buyer") first, then "procuringEntity", and finally any non-"supplier" party. Extract contactPoint.name, contactPoint.email, contactPoint.telephone, contactPoint.url, and address.postalCode.
  2. Public-Sector Domain Verification (isPublicSectorDomain): Classify extracted emails against institutional UK suffixes (.gov.uk, .nhs.uk, .nhs.net, .police.uk, .mod.uk, .ac.uk, .parliament.uk, .sch.uk, .org.uk) and fall back to scanning tender.description if contactPoint.email is blank.
  3. Incumbent & Renewal Intelligence (award Stage): Cross-reference awards[].suppliers[] against parties[] where roles.includes("supplier") to capture winning vendor names, SME status (details.scale === "sme"), and contract end dates for upcoming framework renewals.

Rate-Limit Pitfall on /Published/* Endpoints: Sending concurrent bursts to /Published/Notice/releases/{id}.json frequently triggers HTTP 429 throttling. A resilient extractor queries /Published/Notices/OCDS/Search as a single bulk call when browsing latest notices, and pairs POST /api/rest/2/search_notices/json with GET /api/rest/2/get_published_notice/json/{id} fallback whenever /Published/* returns 429 or 404.

Option C — Direct OCDS Query in Python (requests) + Scheduled n8n Workflow

Query the public OCDS endpoint directly in Python or import daily-uk-gov-tenders-alert.n8n.json into n8n:

uk_gov_ocds_buyer_emails.py 
import requests

resp = requests.get(
    "https://www.contractsfinder.service.gov.uk/Published/Notices/OCDS/Search",
    params={"limit": 10, "stages": "tender"},
    headers={"Accept": "application/json"},
    timeout=20,
)
resp.raise_for_status()

for rel in resp.json().get("releases", []):
    parties = rel.get("parties", [])
    buyer = next(
        (p for p in parties if any(r in ("buyer", "procuringEntity") for r in p.get("roles", []))),
        {},
    )
    cp = buyer.get("contactPoint", {})
    tender = rel.get("tender", {})
    print({
        "ocid": rel.get("ocid"),
        "title": tender.get("title"),
        "buyer": buyer.get("name"),
        "email": cp.get("email"),
        "valueGBP": (tender.get("value") or {}).get("amount"),
        "deadline": (tender.get("tenderPeriod") or {}).get("endDate"),
    })
