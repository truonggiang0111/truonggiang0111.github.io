Portable File Tree

Root Layout (1.0.0)

your-plugin-repo/
├── plugin.json         # agent-plugins.org 1.0.0
├── mcp.json            # stdio or streamable-http
├── skills/
│   └── <skill>/SKILL.md
├── icons/              # <= 50KB SVG or PNG
├── SECURITY.md         # disclosure policy
├── LICENSE             # MIT / Apache-2.0
└── package-lock.json   # lockfile + SHA-pinned CI
Key Spec Rules

Avoid 4 Common Packaging Rejections

1. Declare "type": "stdio" or "streamable-http" inside mcp.json (never leave transport omitted).

2. Keep OpenAI UI metadata inside extensions.com.openai.interface — don't mix root plugin.json with a legacy .codex-plugin/ overlay.

3. Pin GitHub Actions by full 40-char commit SHA with persist-credentials: false and zero hardcoded secrets.

4. Include SECURITY.md, LICENSE, and icons under 50 KB to hit 100/100 in HOL Guard.
