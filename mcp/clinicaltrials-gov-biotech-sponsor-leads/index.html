1. Essie Filtering + ~96% Context-Token Reduction

A naive GET /api/v2/studies call downloads complete eligibility criteria, results tables, and adverse-event histories. In ttyan0111/clinical-trials-biotech-leads, two query optimizations keep cloud memory at ~62–65 MB and sub-2.3s runtime:

  1. Essie Server-Side Commercial Filtering: Combine filter.overallStatus=RECRUITING,NOT_YET_RECRUITING with filter.advanced=AREA[LeadSponsorClass]INDUSTRY AND AREA[Phase](PHASE1 OR PHASE2 OR PHASE3) alongside query.term, query.spons, and query.locn (plus direct /studies/{NCT_ID} lookup for exact NCT\d{8} IDs).
  2. 8-Module fields Projection: Request strictly IdentificationModule|StatusModule|SponsorCollaboratorsModule|DescriptionModule|ConditionsModule|DesignModule|ArmsInterventionsModule|ContactsLocationsModule — cutting raw JSON weight by roughly 96% while keeping every commercial and contact field intact.
  3. 3-Tier Contact Deduplication: Separate centralContacts[] (corporate sponsor emails + corporateSponsorDomain excluding webmail) from overallOfficials[] (PI names + affiliations) and email-prioritized, deduplicated locations[].contacts[] site leads.

Option C — Python (requests): Direct ClinicalTrials.gov API v2 with fields Projection

clinical_trials_biotech_v2.py 
import requests

FIELDS = "|".join([
    "IdentificationModule",
    "StatusModule",
    "SponsorCollaboratorsModule",
    "DesignModule",
    "ContactsLocationsModule",
])

resp = requests.get(
    "https://clinicaltrials.gov/api/v2/studies",
    params={
        "query.term": "CAR-T",
        "query.locn": "United States",
        "filter.overallStatus": "RECRUITING,NOT_YET_RECRUITING",
        "filter.advanced": "AREA[LeadSponsorClass]INDUSTRY AND AREA[Phase](PHASE1 OR PHASE2 OR PHASE3)",
        "fields": FIELDS,
        "pageSize": 10,
    },
    timeout=20,
)
resp.raise_for_status()

for study in resp.json().get("studies", []):
    ps = study.get("protocolSection", {})
    nct = ps.get("identificationModule", {}).get("nctId")
    sponsor = ps.get("sponsorCollaboratorsModule", {}).get("leadSponsor", {}).get("name")
    central = ps.get("contactsLocationsModule", {}).get("centralContacts", [])
    emails = [c["email"] for c in central if c.get("email")]
    print(f"{nct} | {sponsor} | {', '.join(emails) or 'No central email'}")
