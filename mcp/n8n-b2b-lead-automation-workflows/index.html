Frequently Asked Questions

How do I import these 16 workflows into n8n in one click?

Click Copy Workflow JSON on any card and press Ctrl + V (Windows/Linux) or Cmd + V (macOS) directly on an empty n8n canvas. Alternatively, click Copy Raw Import URL and choose Import from URL inside n8n's top-right menu.

Which workflows run immediately with zero API keys?

n8n-ai-agent-stdio-zero-key-mcp-research.n8n.json (via npx -y github:truonggiang0111/b2b-market-intel-mcp), daily-clinical-trials-biotech-sponsor-leads.n8n.json, weekly-atlassian-jira-app-churn-leads.n8n.json, and weekly-wordpress-woocommerce-plugin-churn-leads.n8n.json query public REST APIs / STDIO MCP with zero keys required.
