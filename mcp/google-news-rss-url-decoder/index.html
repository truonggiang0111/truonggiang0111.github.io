1. Why Legacy Base64 Decoders & HTTP Redirects Break on Modern CBMi Links

Before mid-2024, developers could strip the path slug after /articles/, URL-safe Base64-decode the CBMi... protobuf bytes, and regex out a plaintext https://reuters.com/... string. Today, decoding modern Google News slugs yields an internal token prefixed with AU_yqL... instead of a destination URL:

What breaks in RAG pipelines: Passing raw news.google.com/rss/articles/CBMi... URLs into standard fetch, LangChain WebBaseLoader, or basic LLM browse tools returns the DotsSplashUi shell without redirecting (`HTTP 200` on `news.google.com`). Your vector database indexes zero article prose and cites useless redirect wrappers instead of canonical publisher domains.

2. The 4-Stage Zero-Proxy Resolution Pipeline (`Fbv4je` RPC)

In ttyan0111/google-news-ai-article-extractor, every RSS item runs through a deterministic 4-stage pipeline using browser-TLS HTTP (got-scraping) with zero residential proxy cost by default:

  1. Stage 1 — Redirect & data-n-au Check: Fetch the news.google.com wrapper with Referer: https://news.google.com/. If an HTTP 301/302 lands off-Google or the HTML exposes data-n-au="https://...", return immediately.
  2. Stage 2 — Signed DotsSplashUi batchexecute Handshake (rpcids=Fbv4je): Parse three server-issued attributes from the splash HTML — data-n-a-id (article token), data-n-a-ts (Unix timestamp), and data-n-a-sg (HMAC signature) alongside the data-p locale array — then POST an application/x-www-form-urlencoded f.req payload (garturlreq) to https://news.google.com/_/DotsSplashUi/data/batchexecute?rpcids=Fbv4je. Strip Google's )]}' XSSI prefix and read ["garturlres", "https://publisher.com/..."].
  3. Stage 3 — Legacy Base64 Fallback: For archival stories still encoding raw URLs inside protobuf bytes (excluding AU_yqL tokens), fall back to offline Base64 extraction.
  4. Stage 4 — Boilerplate-Stripped RAG Text & PR Signal Classification: Concurrently fetch the decoded publisher URL, strip scripts/nav/ads/cookie banners, extract up to 12,000 chars of clean prose plus author and og:image, tag 6 B2B PR categories (funding_mna, product_launch, layoff_risk, partnership, controversy_legal, earnings_growth), and gracefully fall back to the clean RSS snippet if a publisher enforces a hard 401/403 paywall.

6. Frequently Asked Questions

Why did Python Base64 decoding stop working on news.google.com/rss/articles/CBMi links?

Older CBMi protobuf payloads embedded plaintext http/https publisher URLs directly inside the Base64 string. Modern Google News RSS articles wrap opaque AU_yqL server tokens instead, requiring a signed POST request to /_/DotsSplashUi/data/batchexecute?rpcids=Fbv4je using data-n-a-ts and data-n-a-sg attributes extracted from the splash HTML.

Does decoding Google News CBMi URLs require residential proxies?

No. In verified Apify Cloud production runs (aWT3emzrd5gJMK9Di), ttyan0111/google-news-ai-article-extractor decoded 20/20 Google News URLs and extracted 15/20 full publisher articles in 6.47s at 108.3 MB RAM with $0 proxy cost.

What happens if a destination publisher has a hard paywall?

You still receive the verified decoded url (with urlDecoded: true), sourceName, publishedAt timestamp, and PR marketSignals, while articleText cleanly falls back to the stripped RSS summary without failing the batch.
