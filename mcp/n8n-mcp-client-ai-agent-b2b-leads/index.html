5. agentSummary & RUN_SUMMARY: Why Low-Token Design Matters

The n8n Agent Context Bottleneck: Passing 15 raw ClinicalTrials.gov study JSON documents or 50 full-text WordPress churn reviews into an n8n AI Agent's tool response can easily consume 40,000–120,000 tokens in a single turn — inflating OpenAI/Anthropic bills and triggering context truncation before the agent writes a single outreach draft.

Every tool across our stack follows a two-tier payload design verified on Apify Cloud (256 MB RAM, $0 proxy cost):

  • Tier 1 — Aggregate RUN_SUMMARY (Key-Value Store): Compact JSON counters (vendorEmailsFound, topPainCategories, highInstallVulnerablePlugins, corporateSponsorEmails) let an Agent evaluate signal density first before iterating records.
  • Tier 2 — Compact Per-Item agentSummary: Every dataset record includes a single-line summary string (typically 140–240 characters) packing title, scale, rating, verified email/domain, and top pain tags.
  • Empirical Payload Hygiene: ClinicalTrials.gov 8-module fields projection trims ~96% JSON bloat (extracting 24/25 central emails & 183 unique Biotech + PI emails in 2.18s), while WordPress.org api.wordpress.org/plugins/info/1.2/ field selection cuts plugin metadata payload size by ~95%.

Frequently Asked Questions

When should an n8n AI Agent use Streamable HTTP MCP vs npx STDIO MCP vs n8n-nodes-b2b-market-intel?

Use Streamable HTTP (https://mcp.apify.com) on n8n Cloud or restricted containers where subprocess execution is disabled; use npx STDIO on self-hosted n8n for 3 instant zero-key tools; and install n8n-nodes-b2b-market-intel (usableAsTool: true) when you want native credential storage and direct ai_tool wiring across all 18 operations.

How does agentSummary prevent LLM context window overflow in n8n AI Agents?

Instead of dumping raw nested HTML or bloated REST documents into the Agent's prompt, each item carries a concise one-line agentSummary string alongside aggregate RUN_SUMMARY metrics so Agents can shortlist leads inside < 2,000 tokens.

Does the zero-key STDIO MCP server work without an Apify API key?

Yes. npx -y github:truonggiang0111/b2b-market-intel-mcp starts immediately with no API key required for decode_google_news_url, preview_uk_gov_tenders, and preview_clinical_trials_leads, and unlocks 5 cloud batch tools when APIFY_TOKEN is present.
